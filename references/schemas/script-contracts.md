# Script Contracts

- `scan_repo.py`: scan path metadata, classify paths, detect CFC methods, redact secrets.
- `detect_stack.py`: detect CFML, PHP, Node/JS, Python, MySQL, MSSQL, and Docker indicators.
- `write_templates.py`: create exact generated Atlas manifest and run fail-closed verification.
- `bootstrap_atlas.py`: orchestrate scan, create, populate, verify, and report.
- `maintain_atlas.py`: update or check Atlas without inventing facts.
